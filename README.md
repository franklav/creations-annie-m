# Portfolio d'Artiste Peintre

Site web portfolio pour présenter des créations artistiques, toiles, démarche et coordonnées.

Et voici, une page pour vous présenter mes créations!

## 🚀 Fonctionnalités

- Galerie d'œuvres adaptative (Masonry Grid)
- Modale plein écran (Lightbox) pour afficher les détails des toiles
- Section biographie et expositions
- Design épuré, rapide et optimisé pour tous les écrans
- Hébergé gratuitement sur GitHub Pages avec domaine personnalisé

## 📁 Structure du projet

```text
├── index.html       # Code principal du site (HTML / Tailwind CSS)
├── CNAME            # Configuration du domaine personnalisé
└── images/          # Photos des œuvres et photo de l'artiste
```
